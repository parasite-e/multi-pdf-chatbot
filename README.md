# Multi-pdf-chatbot
This project is an intelligent Retrieval-Augmented Generation (RAG) system that allows users to ask natural language questions and receive context-aware answers from the content of Link, PDF, DOCX, Text documents

# AI PDF Chatbot – RAG Q&A System (LangChain + Hugging Face + FAISS)

Ask questions from your uploaded Link, PDF, Text, DOCX documents using an AI-powered chatbot built with LangChain, FAISS, and free Hugging Face models. No paid API like OpenAI needed!

##  Features

-  Chat with any Link, PDF, Text, DOCX document
-  Smart context-aware search using FAISS vector DB
-  Uses Hugging Face's FLAN-T5 (Free model)
-  Upload your own LInk, PDFs, DOCX
-  Built with LangChain for RAG-style question answering
-  Deployable on Streamlit Cloud or HuggingFace Spaces

---

## Tech Stack

- **LangChain** – Retrieval-Augmented Generation pipeline
- **FAISS** – Fast vector similarity search
- **Hugging Face Transformers** – Free open-source LLM (e.g., FLAN-T5)
- **Streamlit** – Web UI
- **dotenv** – API key management
